# GitOps

Branch deployments with F5 Distributed Cloud, Terraform, and Kubernetes state.

Deploy an isolated F5 Distributed Cloud HTTP load balancer for each Git branch. The custom xcsh Terraform provider manages namespaces, origin pools, and load balancers. Kubernetes Secrets preserve state and recovery configuration; Leases serialize writers. [English documentation](https://f5-sales-demo.github.io/gitops/en/).
