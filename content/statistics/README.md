# Statistics

Retrieve statistics from the F5 Distributed Cloud API across resource types.

Start with the [Statistics guide](https://f5-sales-demo.github.io/statistics/en/)
for shared cURL setup and resource queries. The current HTTP deployment
demonstrates access logs, load balancer and origin metrics, application health,
API activity, WAF counters, and security events. Additional platform families
require separate deployment and verification.

The [Terraform reference](https://f5-sales-demo.github.io/statistics/en/deployment/)
and [Demo readiness](https://f5-sales-demo.github.io/statistics/en/verification/)
support the existing deployment. Resource queries require no infrastructure apply.
