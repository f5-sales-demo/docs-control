# Certificate Management

Prepare and encrypt certificate keys for F5 Distributed Cloud.

- [Terraform](docs/en/terraform/index.md) deploys independently owned certificate resources
  with native provider Blindfold preparation and no xcsh installation.
- [xcsh](docs/en/xcsh/index.md) prepares and applies certificate manifests through the CLI.

[English documentation](docs/en/index.md) includes input, lifecycle, verification, and
certificate-surface references. Both retained demonstrations share public certificate
material while each tool owns separate XC resources.
